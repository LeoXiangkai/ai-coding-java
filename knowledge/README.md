# Knowledge Base

This directory stores reusable, sanitized knowledge for `ai-coding-java`.

It is not a place for raw logs, real customer data, credentials, production curl output, or target-project private business details.

## Structure

```text
knowledge/
  company-rules/
  bug-roots/
  sql-transaction-cases/
  project-rule-examples/
```

## What Belongs Here

1. Company-level Java engineering rules.
2. Reusable bug root-cause patterns.
3. SQL, transaction, async, cache, and idempotency lessons.
4. Sanitized examples showing how project business rules should be recorded.

## What Does Not Belong Here

1. Real credentials, tokens, keys, or internal hostnames.
2. Raw logs or large command output.
3. Real personal data or business-sensitive data.
4. One-off task progress.
5. Target-project facts that are not reusable outside that project.

## Entry Format

Use `templates/knowledge-entry-template.md`.
