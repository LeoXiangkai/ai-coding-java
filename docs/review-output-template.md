# ai-coding-java Review Output Template v1.1

Review 只审本次变更，不做全仓泛审。

## 输出格式

```text
P0 阻断问题：
- 无 / 文件:行号 问题 影响 修复建议

P1 必修问题：
- 无 / 文件:行号 问题 影响 修复建议

P2 建议问题：
- 无 / 文件:行号 问题 建议

验证证据：
- 命令：
- 结果：

Not-tested：
- 未执行：
- 原因：
- 剩余风险：

是否允许交付：
- 是 / 否 / 需负责人豁免
```

## 判定口径

1. 有 P0：不允许交付。
2. 有 P1：原则上不允许交付；负责人豁免后可继续，但必须记录原因。
3. 只有 P2：可交付，建议进入后续优化。
4. 验证缺口不等于失败，但必须如实报告。
5. 不允许只写 LGTM，不允许没有文件/行号的泛泛评价。
