# 测试深度评分

每维 1–3 分：业务影响（非核心 / 核心分支 / 主流程或合规）、变更范围（单点 / 2–3 模块 / 跨模块或进程）、数据敏感度（无 / 一般 / PII 或合规）、发生概率（低 / 中 / 高频）、可逆性（可撤销 / 需人工恢复 / 不可逆）。

| 总分 | 深度 |
|---|---|
| 5–7 | 正向为主，抽样异常与边界 |
| 8–11 | 正向 + 关键反向（权限、临界业务规则） |
| 12–15 | 正向 + 全量反向，完整保留截图、日志和请求响应 |

老系统默认只做正向；仅高分流程另行评估关键反向。新需求无论分数高低都要生成反向用例，分数决定广度和深度。
