# ai-coding-java Artifacts

本目录是目标项目初始化后的研发一体化过程产物参考目录。

在业务项目中，推荐按任务建立子目录：

```text
.ai-coding-java/artifacts/<work-id>/
  requirement-brief.md
  design-brief.md
  test-case-brief.md
  release-impact.md
```

原则：

1. 只记录对本次研发有复用或追溯价值的内容。
2. 不保存运行日志、原始客户数据、真实凭据、未脱敏生产输出。
3. 本地辅助模式下可不提交 artifacts。
4. 团队协作模式下，只提交已脱敏、已确认、能帮助 Review 或验收的产物。
